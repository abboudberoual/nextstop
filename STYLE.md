# Content rules for Next Stop questions

These come from Abboud's MECH 361 prep brief (`midterm-prep.md` in the MECH project) and apply to every course. Class projects writing to `_claude/nextstop/*.json` should follow them too.

## Explanations
1. **Set every equation up in full before isolating anything.** Write the general form, say what each point or term is, give each value with its reason, and cancel with a stated reason ("horizontal, so γz cancels"). Only then isolate and substitute.
2. **One formula per line.** Use `\n` between lines in the JSON. Define every symbol the first time it appears.
3. **Explain every sign in plain words**, e.g. "v_θ < 0 at θ = 90° means to the right, downstream".
4. **Show the differentiation or integration step** that matters: rewrite before differentiating, keep the "+ f(x), then find f′(x)" step, and name the chain or product rule.
5. **Units on every numeric answer.**

## Where each formula comes from (tag it)
- `(sheet p.N)` or `(sheet p.N, <row>)`: may be used straight from the course formula sheet.
- `(derived)`: a specialised result, derived in at most 4 lines from sheet formulas or basic physics. It never appears without its derivation.
- `(definition, not on the sheet)`: basic definitions (τ = μ du/dy, ζ, Γ, q = ψ₂ − ψ₁, Re, …).
- `(know this…)`: MECH 361 allows only lift F_y = −ρUΓ (Kutta–Joukowski) here.

The app shows these tags as coloured chips. Use the **sheet's notation**. MECH 361 examples: source v_r = m/(2πr) with m = Q; vortex v_θ = Γ/(2πr); laminar boundary layer δ/x = 5.48/√Re_x. Where the sheet has a misprint (MECH polar ω_z), use the correct form and say so once.

## Accuracy
- Check every number in Python before writing it.
- When rewriting a question, keep the final answer unless a number turns out to be wrong.

## Visuals
- Every geometry question gets an exam-style sketch: body, U, axes, r and θ, the given points and stagnation points. Sketches live in `content/figures.json` (generated by `content/figgen/`), with streamlines traced from the actual ψ. Reference one with `"figure": "<key>"`.
- Use `currentColor` so sketches read in both light and dark mode.

## Quiz behaviour
- Only the first try at a card counts, both for the score and for spaced repetition. The in-session retry is practice.
- Nothing reveals the answer before you commit (no hover hints).

## Post-midterm habits (asked as cards in the Exam habits topic)
- Write r sin θ = y before taking a limit.
- Check which surface (and which y) a shear question means.
- Put a unit on every final answer.
